# Changelog

All notable project changes are documented here.

## 1.0.0 - 2026-07-12

- Publish eight consulting skills spanning transformation, strategy, diligence, execution, communication, presentations, and case coaching.
- Add a realistic worked example and two rubric-based evaluation scenarios for every skill.
- Add a cross-platform installer with safe overwrite behavior, dry runs, custom destinations, and machine-readable listing.
- Add deterministic per-skill and all-skills release archives with SHA-256 checksums.
- Expand the machine-readable catalog with paths, descriptions, examples, outputs, and tags.
- Validate catalog synchronization, internal Markdown links, reference routing, evaluation coverage, metadata, and secrets.
- Test on Python 3.10, 3.12, and 3.13 across Linux and Windows.

## 0.4.0 - 2026-07-12

- Add `market-sizing-sanity-check` with independent triangulation and a worked sizing example.
- Add the first machine-readable skill catalog.

## 0.3.0 - 2026-07-09

- Add `value-creation-plan`, `consulting-case-interview-coach`, and `consulting-template-style`.
- Add repository regression tests.

## 0.2.0 - 2026-07-06

- Add `market-map-signal-scan` and supporting signal references.

## 0.1.0 - 2026-07-03

- Publish the initial transformation, diligence, and executive memo skills.
