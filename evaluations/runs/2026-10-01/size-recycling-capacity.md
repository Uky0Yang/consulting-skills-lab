# Recycling capacity — current-session response

## Decision and boundary

The fictional supply gate fails in all three supplied cases. Base year-five constrained throughput is 4,000 INPUT tonnes/year, not 20,000 tonnes of feedstock merely because that capacity is announced. This is a training calculation, not an investment recommendation or a permit assessment.

## Constraint model

For each case, processed input = min(accessible feedstock, operational input capacity, qualified demand in equivalent input tonnes). Nameplate 20,000 becomes operational capacity of 16,000 after downtime; do not apply downtime twice.

The independent collection-contract inventory supports only 4,000 input tonnes/year in the base. It anchors accessible supply, not selling price, permits or the 12,000-tonne demand assumption. No growth bridge supports the high case beyond the supplied fictional scenario.

## Break-even and evidence gate

The £150 contribution is per INPUT tonne, already net of variable costs. Required input = £1,200,000 fixed cost / £150 = 8,000 tonnes/year. Required operational utilization = 8,000/16,000 = 50% (or 40% of nameplate; do not mix denominators).

Base contribution is £600,000, leaving a £600,000 annual operating shortfall before any unprovided capital costs. Low/high shortfalls are £840,000/£300,000. Even high accessible feedstock remains below 8,000 tonnes. Recovery yield is used to report output, not multiplied into an input-tonne contribution margin.

The next gate is evidence for at least 8,000 qualified accessible input tonnes/year on a consistent contract/time basis, or a documented change to contribution/fixed costs. Commercial should validate contract delivery and feedstock quality; operations should test yield/uptime; finance should validate the contribution definition and omitted capital economics. Regulatory specialists must assess permits separately; no permission is assumed.
