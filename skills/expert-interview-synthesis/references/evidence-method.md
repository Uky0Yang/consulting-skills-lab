# Interview evidence method

## Ledger discipline

Use one row per material evidence item. Preserve raw source location. A verbatim quote must be in the transcript; when only notes exist, write a paraphrase and record that the original wording is unavailable. A source identifier should be useful without exposing a participant's name.

Capture role, knowledge basis, date/period, question context and possible incentives. For numbers, capture unit, scope, denominator and whether the participant has access to the underlying data. If these are missing, request verification rather than normalizing the claim silently.

## Independent counts

Five quotations from one person are one participant, not five votes. Two people describing the same incident can corroborate the incident but do not establish that it is frequent. If all three cite the same vendor presentation, record one underlying source with three repetitions.

Report sample coverage, not population prevalence. Do not weight a view solely by seniority or discard a negative case because it is inconvenient.

## Confidence and conflict

| Status | Appropriate use |
| --- | --- |
| Corroborated observation | Direct, scoped accounts aligned with an independent record; cite both |
| Directional finding | Relevant qualitative accounts with incomplete coverage; useful for prioritizing a test |
| Unverified claim | Estimate, hearsay or an unchecked number; retain attribution |
| Contested | Material evidence conflicts and the proposed explanation remains untested |

For each conflict, compare period, segment, definitions, firsthand access and incentives. Write a next check and what each result would mean for the decision. Do not force a consensus or average incomparable quantities.

## Findings structure

“Within segment S and period T, evidence E1/E2 suggests X; E3 conflicts. Confidence is directional because C. Before decision D, owner O should test Y.” A concise statement can still expose its limits.

Store raw materials only in the permitted location. Redact identifying details in shared outputs; preserve a private lookup only if necessary and authorized. Confidentiality markings are constraints, not decorative labels.
