# Consulting House Styles

Use these as informed visual systems, not official firm brand standards.

## Shared Consulting Grammar

- Use a claim title that states the implication.
- Make one proof object dominate the page.
- Use neutral greys for context and one accent for the answer.
- Keep alignment exact and spacing deliberate.
- Place sources, caveats, and page markers quietly at the bottom.
- Prefer flat analytical composition over rounded cards, gradients, shadows, and decorative icons.
- Maintain a clear reading path: claim, evidence, implication.

## McKinsey-Informed

### Character

Sparse, senior, and editorial. Use it when the recommendation should feel calm and decisive rather than visually forceful.

### Typography

- Display and selected headline treatment: Georgia.
- Body, charts, tables, labels, and footnotes: Arial.
- Use black for prose and deep navy for restrained emphasis.
- Preserve generous line spacing and whitespace.

The reference sample contains only three slides. Treat headline and cover patterns as directional rather than a complete layout library.

### Palette

| Role | Color |
| --- | --- |
| White | `#FFFFFF` |
| Black | `#000000` |
| Deep navy | `#051C2C` |
| Bright blue | `#00A9F4` |
| Teal | `#19D3C5` |
| Light grey | `#E6E6E6` |

Use a blue or teal series only when it carries the main evidence. Avoid turning body text into accent color.

### Layout

- High-whitespace cover with restrained brand area.
- Left-aligned editorial claim.
- Thin separators and compact evidence panels.
- Qualitative drivers on the left and quantified proof on the right.
- Minimal recommendation chrome; let the headline carry the conclusion.

### Best Uses

- Executive summary.
- Board recommendation.
- Market sizing.
- Investment thesis.
- Sparse strategic synthesis.

## Bain-Informed

### Character

Dense, commercial, and explicitly analytical. Use it for chart books and decisions where the audience needs to see the fact base.

### Typography

- New slide text: Verdana.
- Titles commonly sit around 24-28 pt in the reference.
- Body and chart labels commonly use 9-14 pt in dense layouts.
- Imported charts may contain Arial; normalize new content to Verdana unless preserving an existing chart.

### Palette

| Role | Color |
| --- | --- |
| White | `#FFFFFF` |
| Black | `#000000` |
| Bain red | `#CC0000` |
| Dark grey | `#777777` |
| Mid grey | `#B2B2B2` |
| Light grey | `#DDDDDD` |
| Support blue | `#006393` |
| Support cyan | `#0091BF` |
| Support teal | `#61A48D` |
| Support olive | `#738C1F` |
| Support gold | `#D7A154` |

Red means answer, risk, gap, or chosen scenario. It should not become a background system.

### Layout

- Thin red top rule as persistent chrome.
- Claim title at top left.
- Wide chart with a right-side implication column.
- Dense table with one red row, column, or cell group.
- Small multiples aligned to a shared baseline.
- Grey baseline or market context with one red focal series.
- Red annotation circles, arrows, or boxes used sparingly.

### Best Uses

- Commercial due diligence.
- Market growth and share.
- Customer segmentation.
- Competitive benchmarking.
- Pricing, cost, and productivity.
- Scenario comparison.

## BCG-Informed

### Character

Structured, strategy-led, and process oriented. It is slightly more open than the Bain-informed system while retaining analytical density.

### Typography

- Arial throughout.
- Titles commonly use approximately 24 pt.
- Body and chart labels commonly use 9-16 pt.
- Use green for titles, selected paths, recommendation strips, and key headers.

### Palette

| Role | Color |
| --- | --- |
| White | `#FFFFFF` |
| Black | `#000000` |
| Primary green | `#177B57` |
| Soft green | `#5BAD82` |
| Pale green | `#BCDEC2` |
| Blue-grey | `#79A2B3` |
| Light grey | `#E2E2E2` |
| Orange | `#DC6E00` |
| Red | `#C41300` |
| Yellow | `#E7D475` |
| Gold | `#DCC05A` |

Green means selected path, client position, recommendation, or positive result. Orange and red identify constraints or downside.

### Layout

- Green claim title and thin top rule.
- Two-column strategy and evidence page.
- Full-width chart with a bottom green takeaway strip.
- Horizontal process with stage gates and shaded phases.
- Matrix or scatter with a highlighted zone.
- Green table headers or one highlighted row.
- Neutral map base with compact markers and side evidence.

### Best Uses

- Corporate strategy.
- Market entry.
- Portfolio review.
- Operating model.
- Transformation roadmap.
- Value chain and process.
- Maps and timelines.

## Selection Test

Choose the style whose default answer to these questions fits the artifact:

| Question | McKinsey-informed | Bain-informed | BCG-informed |
| --- | --- | --- | --- |
| How much evidence per page? | Low to medium | High | Medium to high |
| How explicit is the visual answer? | Headline-led | Red annotation-led | Green path/takeaway-led |
| What is the dominant proof? | Synthesis or compact chart | Dense chart/table | Strategy structure/process |
| What should the page feel like? | Editorial | Commercial | Strategic |
