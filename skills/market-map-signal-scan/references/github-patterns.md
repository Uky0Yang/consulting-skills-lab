# GitHub Pattern Notes

These notes summarize public discovery patterns observed around popular agent-skill and market-research repositories in July 2026. Use them for positioning, not as copied content.

## What Is Popular

- Large curated skill lists are getting meaningful attention because users need discovery across Claude Code, Codex, Cursor, Gemini CLI, and similar tools.
- Broad deep-research skills are popular because they solve a universal problem: gathering sources, synthesizing evidence, and producing reports.
- Market-research-specific agent apps exist, but many are demos or narrow multi-agent applications rather than portable consulting workflows.
- Competitive intelligence projects often focus on scraping or report automation; fewer focus on how to judge whether a market claim is decision-grade.

## Differentiation for This Skill

This skill should not compete as another "deep research" wrapper. It should be different in four ways:

1. Market map first: segment by buyer job and market structure before writing a report.
2. Signal confidence: label evidence quality before making recommendations.
3. Opportunity gap logic: require buyer pain, budget, timing, access, and defensibility.
4. Decision output: end with enter, invest, build, partner, monitor, or avoid.

## Public Reference Points

- VoltAgent/awesome-agent-skills: high-star discovery hub for agent skills.
- heilcheng/awesome-agent-skills: community-oriented skill guide and directory.
- Weizhena/Deep-Research-skills: deep research skill with market research among its use cases.
- GitHub competitive-analysis and market-research topics: many small projects focus on competitive analysis, market research agents, and business intelligence apps.

Use these only as category context. Do not copy their instructions, prompts, README language, or file structures.
