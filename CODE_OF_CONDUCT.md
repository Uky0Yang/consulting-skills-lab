# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project respectful and harassment-free for everyone, regardless of background, identity, experience, or viewpoint.

## Expected behavior

- Give specific, constructive feedback on the work.
- Welcome questions and different levels of experience.
- Respect confidentiality, copyright, and data ownership.
- Credit sources and contributors appropriately.
- Focus disagreements on evidence, tradeoffs, and project goals.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sexualized attention, deliberate disclosure of private information, and sustained disruption are not acceptable.

## Enforcement

Report conduct concerns privately to the repository owner through their GitHub profile. Maintainers may edit or remove contributions, comments, issues, or other participation that violates this code and may temporarily or permanently restrict participation.

This project uses a concise adaptation of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
